# SkillFactory-one

Учебные проекты и задания курса SkillFactory.

## Проект 1: анализ резюме HeadHunter

[Ноутбук с анализом](Блок%201/Project-1/PROJECT-1.ipynb) содержит исследование структуры данных, преобразование признаков, графики и очистку резюме. Данные учебные; значения зарплат отражают ожидания соискателей.

### Данные и запуск

1. Скачайте [датасет резюме с Google Диска](https://drive.google.com/file/d/1UfafIlnZu_YOK8UEbRrOT7056RPuFUwG/view?usp=drive_link) и положите файл `dst-3.0_16_1_hh_database.csv` в папку `Блок 1/Project-1` рядом с ноутбуком. Из-за размера файл исключён из Git.
2. Файл курсов валют `ExchangeRates.csv` уже находится в папке проекта.
3. Установите Python и библиотеки `pandas`, `numpy`, `matplotlib`, `seaborn`, `plotly` и `jupyter`, затем откройте ноутбук из папки проекта и выполните ячейки по порядку.

Графики построены с помощью Matplotlib и Seaborn и сохранены в выводах ноутбука как изображения, поэтому отображаются на GitHub без отдельных HTML-файлов.
